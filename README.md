Organ Donation Management System



A web-based Organ Donation Management System developed using PHP, MySQL, HTML, CSS, and JavaScript.



Features



\- User registration and login

\- Donor management

\- Organ donation requests

\- Donation records

\- Admin dashboard

\- User and request management



Technologies Used



\- PHP

\- MySQL

\- HTML

\- CSS

\- JavaScript

\- Bootstrap



Installation



1\. Install XAMPP.

2\. Copy the project folder into `htdocs`.

3\. Start Apache and MySQL.

4\. Create a database named `organdb`.

5\. Import your local database SQL file into phpMyAdmin.

6\. Open `http://localhost/organdb/` in your browser.
